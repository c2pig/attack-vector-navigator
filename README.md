# Attack Vector Navigator

An interactive TTP attack path simulator with 39 scenario-based challenges covering common penetration testing attack chains.

## Features

- 39 curated attack scenarios (AD, web, Linux/Windows privesc, pivoting, credentials)
- Step-by-step TTP walkthrough with command-level intent
- Scenario filtering by category and difficulty
- Hosted on GitHub Pages

## Live Site

https://c2pig.github.io/attack-vector-navigator/

## Usage

Open `index.html` locally or visit the live site above.
